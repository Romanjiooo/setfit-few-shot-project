# Efficient Few-Shot Learning Without Prompts (SetFit)

Учебный проект по дисциплине NN второго семестра программы VK Education посвящён разбору статьи [Efficient Few-Shot Learning Without Prompts](https://arxiv.org/abs/2209.11055).
В статье представлен метод SetFit, позволяющий обучать классификатор текстов по небольшому количеству размеченных примеров каждого класса без использования промптов.
Обучение состоит из контрастивного дообучения Sentence Transformer на парах текстов и последующего обучения классификатора на полученных векторных представлениях.
В рамках проекта планируется изучить предложенный подход, воспроизвести его реализацию и провести собственные эксперименты с изменениями исходного метода.
